### Определение возраста покупателей

Описание данных:

Данные взяты с сайта ChaLearn Looking at People. Они находятся в папке /datasets/faces/.

В вашем распоряжении одна папка со всеми изображениями (/final_files) и CSV-файл labels.csv с двумя колонками: file_name и real_age.

Извлечь данные из папки вам поможет новый метод ImageDataGenerator —flow_from_dataframe(dataframe, directory, ...).

Вывод:
Была поставлена задача построить и обучить модель, которя поможет определять возраст человека по изображению с камеры со средним абсолютным отклонением MAE не выше 7.

В качестве основы за модель взяли уже предобученную нейросеть с архитектурой ResNet50 и дополнительно обучили её на наших данных без замораживания. В выходном слое, для более точного обучения модели, использовали оптимизацию Adam c шагом обучения lr=0.0001
, а в качестве функции потерь использовалась mean_squared_error, что немного ускорило процесс обучения.

Уже на 7 эпохе модель показала значение по метрике MAE = 6.22, но к 10 эпохе качество на тестовых данных ухудшилось.
Что говорит о начале переобучения.

Можено ограничить можель 7ми эпохами, что также снизит время обучения.
